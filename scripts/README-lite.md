# hashcatGUI

hashcatGUI 是一个面向 Windows 的 hashcat 图形界面工具，用于更方便地配置、运行和管理 hashcat 任务。

## 版本说明

这是轻量版发布包。

- 不内置 hashcat
- 包体更小
- hashcat 可以安装到工具目录下的 `resources/hashcat-current`
- 也可以在 `设置 -> Hashcat 安装目录` 中选择自定义安装目录
- 可以在软件内通过 `设置 -> Hashcat 更新` 下载或更新 hashcat

## 如何启动

双击运行：

```text
HashcatGUI.exe
```

首次启动后，如果提示未检测到 hashcat：

1. 打开右上角 `设置`
2. 如需自定义安装位置，先选择 `Hashcat 安装目录`
3. 点击 `Hashcat 更新`
4. 点击 `检查更新`
5. 点击 `更新 hashcat`
6. 等待安装完成

## 主要功能

- Hash 文本输入或 Hash 文件选择
- 完整 hashcat hash 类型选择
- Hash 类型识别与推荐
- 字典攻击、掩码攻击、Hybrid 攻击、模板候选攻击
- 自定义字符集，例如 `-1 ?l?d`
- 字典资源管理、预览、导入副本、编辑、去重
- 任务历史、结果查看、日志查看
- 串行任务队列
- 设备选择与性能控制
- Hashcat 内置更新
- OpenAI 兼容接口 AI 分析日志与 Hash 咨询

## AI 设置

如需使用 AI 功能：

1. 打开右上角 `设置`
2. 填写 `Base URL`
3. 填写 `API Key`
4. 点击 `测试连接`
5. 从模型列表中选择模型
6. 保存设置

AI 设置保存在本机应用数据目录，不会被本轻量版发布包自带。

## 数据保存位置

任务历史、结果、日志、AI 设置等数据保存在当前电脑的应用数据目录中，不会写入本发布包目录。

轻量版目录通常只包含：

```text
HashcatGUI.exe
README.md
README-LITE.txt
resources/
```
